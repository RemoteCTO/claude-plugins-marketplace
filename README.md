# RemoteCTO Claude Code Plugins

Plugin marketplace for Claude Code.

## Install

```bash
/plugin marketplace add RemoteCTO/claude-plugins-marketplace
```

## Available plugins

| Plugin | Description |
|--------|-------------|
| `timelog` | Automatic time tracking for Claude Code sessions |

### timelog

Logs session activity (prompts, projects, tickets)
as JSONL for timesheet reconstruction.

```bash
/plugin install timelog
```

See [claude-code-timelog](https://github.com/RemoteCTO/claude-code-timelog)
for full documentation.
